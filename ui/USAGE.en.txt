TFHMOD UI 2.5.1-experimental · Windows x64 · OFFLINE P1 ONLY

INSTALL
Download TFHMOD-UI-2.5.1-experimental-windows-x64.zip from the Assets at
https://github.com/Wayne62314/TFHMOD/releases/tag/v2.5.1-experimental
GitHub's automatic Source code archives are not the portable app.
Extract the ENTIRE ZIP to a NEW writable folder, e.g. D:\TFHMOD-UI-251, outside the game.
Keep _internal beside TFHMOD.exe. Python/Frida/Tcl/Tk are bundled; no Setup.cmd needed.
Close older tools and restart the game. Do not mix version files.

START
Start the Steam game to its main menu, run TFHMOD.exe, click English, select options
and Connect to game. Return to character select and enter a NEW match.
New experiments default OFF. Enabling Paprika/Velvet arms keys, not automatic Boss mode.
Focus the game window, release and press hotkeys. U remains the game's pause key.

FEATURES / CHARACTER / SCOPE
- Huggles: P1 Arizona loads Huggles; select artwork may remain Arizona.
- Enhanced Oleander: P1 Oleander, Flag27 enhancement.
- Phase-3 Oleander: P1 Oleander, manual flight, homing sparks, Boss Fred and vortex.
  Not the original scripted boss AI. These existing features allow investigated
  free training / local CPU / local two-player flows, not every offline mode.
- Tianhuo normal Fred experiment: P1 Tianhuo, P2 MUST be ORDINARY Oleander to load
  Uni/Fred normally. F9 summons; Y cleans up. Automatic cleanup after 600 game
  updates (~10 seconds), cooldown 60 updates (~1 second). Existing Fred blocks
  duplicates. This is not the phase-3 I/J/K/L controller; not all Oleander commands
  are ported. Independent resource preloading is not implemented; arbitrary P2
  is NOT supported.
- Paprika Boss experiment: free training / local CPU / local versus, P1 Paprika, any P2.
  F6 while idle toggles Flag27. Story code uses this flag for Boss mode.
  The user confirmed the standalone test runs, but actual enhancement effects
  remain unclear. No claim of complete Boss moves, increased damage or full unlock.
  FG_Attack_Leap/Teleport foreground attacks are NOT mapped.
- Velvet Boss experiment: free training / local CPU / local versus, P1 Velvet, any P2.
  F6 while idle requests Boss_Install. Once in Boss_Wind_Idle, F7/F8/F9 request
  light/medium/heavy Boss icicles. Wait for tornado idle before each attack.
  Story wind push, positioning and the full behavior tree are NOT ported.
  The standalone test was user-confirmed; integrated UI gameplay regression remains.
  Y stops Paprika/Velvet experiments and unchecks them. It does NOT guarantee
  tornado cleanup. QUIT AND RESTART THE GAME AFTER USING VELVET'S TORNADO.
- Baihe Supernova: the isolated orb exits on its first update. NOT implemented
  successfully; the UI option is DISABLED. No orbs, presentation, damage or two-bar cost.

PHASE-3 OLEANDER KEYS (different from normal Fred)
O: toggle flight. WASD: bounded low-altitude movement. P: spark after ~1.5s startup.
I: queue one Boss Fred summon. J/K: left/right attacks. Shift: strong, Ctrl:
combination; modifiers can be combined. L: vortex charge; L again after at least
half a second requests release. Wait for recovery before the next action.
Y: cancel, clean up Fred and restore control. U: game pause.
Ten collision slots are reserved without replacing the stage. Historical red/stuck
states and temporary opponent/Arizona visuals are NOT claimed universally fixed.

TEST
Test one experiment at a time. Paprika: compare F6 on/off for attacks, teleports,
hit reactions and knockdown recovery. Velvet: F6 -> tornado idle -> each F7/F8/F9
-> Y -> RESTART GAME. Tianhuo: required P2 Oleander, F9 -> automatic cleanup ->
cooldown -> F9; repeat three cycles. Unit/build self-tests are not gameplay proof.

SAFETY / REPORTING
Existing features whitelist fightType=0, or fightType=10 with training=1.
Velvet/Paprika now use the same whitelist; P1 only. Newly enabled local matches need gameplay regression. Not all modes, stages, rounds/rematches are verified.
The tool injects JavaScript, hooks native functions and changes process memory;
it does not insert Lua or edit game resources/saves on disk. No game assets bundled.
Crashes and lingering state are possible. Close the tool and restart BEFORE ONLINE PLAY.
Whitelist checks are not an anti-cheat or online-safety guarantee. Never bypass validation.
