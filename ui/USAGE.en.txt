TFHMOD UI 2.4.2-ui-bilingual1 — Windows x64 EXPERIMENTAL

OFFLINE ONLY. Player 1 only. This is an unofficial tool, not a complete recreation
of the story boss. Fred/vortex recovery changes still need in-game verification.

DOWNLOAD AND EXTRACT
Download TFHMOD-UI-2.4.2-bilingual1-windows-x64.zip from:
https://github.com/Wayne62314/TFHMOD/releases/tag/v2.4.2-experimental
The automatic GitHub Source code archives are not the portable application.
Extract the ENTIRE ZIP into a new writable folder, such as D:\TFHMOD-UI-242.
It does not belong in the game directory. Keep _internal beside TFHMOD.exe.
Python, Frida and Tcl/Tk are bundled. No Python installation or Setup.cmd needed.
Do not mix files from different versions. Close all old TFHMOD tools first.

START
1. Completely restart the game, especially after a red/stuck Oleander or a cleanup
   warning. Do not attach to an already-corrupted match as a recovery shortcut.
2. Start the game from Steam and wait at the main menu. Run TFHMOD.exe.
3. Click English at the upper right for English, or 中文 to switch back.
   This translates the interface and displayed history without changing options.
   Click Usage Guide to open this file in the selected language.
4. Select your options, then Connect to game. Return to character select and enter
   a NEW match after connecting; an already-loaded match is not automatically armed.

OPTIONS
- Huggles: P1 selects Arizona; the match loads Huggles. Character-select artwork
  may remain Arizona. P2 is not replaced.
- Enhanced Oleander: P1 selects Oleander; enables flag27 enhancement.
- Phase 3 Oleander: P1 selects Oleander; includes flag27 plus manual flight,
  homing sparks, Fred and vortex. This is NOT the original scripted story AI.

KEYS (game window must be focused)
O                 Enter flight; O again exits and requests cleanup.
W/A/S/D           Move in bounded low-altitude flight.
P                 Homing spark after startup (about 1.5 seconds).
I                 Queue ONE Fred summon until startup/cooldown/action ends.
                  Request expires after about 5 seconds of game updates; Y,
                  leaving flight, changing scenes or losing focus cancels it.
J / K             Fred left / right attack; wait for his entrance/current attack.
Shift + J / K     Strong attacks.
Ctrl + J / K      Combination attacks.
Ctrl+Shift+J / K  Strong combination attacks.
L                 Start vortex after Fred appears. Press L again after charging
                  at least half a second to request release.
Y                 Cancel, clean up Fred and restore ordinary control/position.
U                 Reserved for the game's pause function; the tool does not read U.

Allow the vortex end animation to finish before your next move. Do not repeatedly
press summon during an entrance. Some rejected commands produce English diagnostic
details. If you use a keyboard for both local players, avoid game-key conflicts.
No additional phase-3 controller mappings are included.

FIRST REGRESSION TEST
Free training: P1 Oleander -> O -> I -> wait for Fred -> J/K -> L -> L again ->
wait for recovery -> P -> Y -> O -> I. Repeat at least three cycles.
Only then test local versus CPU, local two-player, round transitions and rematches.
If the tool reports incomplete recovery, stop the match and restart the game.

SCOPE AND KNOWN LIMITATIONS
Supports only investigated ordinary offline free-training / local CPU / local
two-player flows: fightType=0, or fightType=10 with training=1. Other modes are
not supported; this is not a promise of compatibility with all offline modes.
The game executable must match SHA256:
03E20EECE23F39FB1012061A5A7FF92F4B63DA23EB8EB641CF6EE379CBCE373D
Do not bypass version/signature checks after a game update.

The 2.4.1 recovery fixes are regression-tested in simulation, not yet confirmed
to resolve every in-game red/stuck state. An opponent temporarily appearing as
Arizona was reported but not reproduced or confirmed fixed.
Fred reserves ten additional collision slots without replacing the stage.
Not all stages, attack effects or lifecycle paths have been verified.
No story cinematics, original boss AI or new character-select portraits included.

STOP AND REPORT PROBLEMS
Press Y in the game first, then Disconnect or close the tool. Restart the game to
fully clear the session. ALWAYS close the tool and restart before online play.
Offline checks are not an anti-cheat or network-safety guarantee.
Logs are local at logs\ui-hook-<PID>.jsonl beside TFHMOD.exe; not auto-uploaded.
Report tool version, mode, both characters, last keys and the log. Review logs
before sharing. Do not disable security software to run an unsigned executable.
