TFHMOD UI 2.5.0-experimental · Windows x64 · 仅限离线 P1

安装
从 https://github.com/Wayne62314/TFHMOD/releases/tag/v2.5.0-experimental 的 Assets
下载 TFHMOD-UI-2.5.0-experimental-windows-x64.zip，不是 Source code。
完整解压到新的可写目录，例如 D:\TFHMOD-UI-250。不必放进游戏目录。
保留 TFHMOD.exe 旁边整个 _internal。包含 Python/Frida/Tcl/Tk，无需 Setup.cmd。
先关闭所有旧工具并重启游戏；不要混用不同版本的文件。

开始
1. 从 Steam 启动游戏到主菜单，运行 TFHMOD.exe。
2. 右上角 English / 中文切换语言；使用说明按钮打开当前语言指南。
3. 勾选需要的功能，点击连接游戏，返回选角重新进入新场次。
4. 新功能默认关闭。勾选 Paprika / Velvet 只准备按键，不会自动开启 Boss。
5. U 始终留给游戏暂停。快捷键要求游戏窗口有焦点，松开再按，不排队打断动作。

功能、角色及模式
- 大熊：P1 选 Arizona，进场替换成 Huggles，预览可能仍为 Arizona。
- 普通强化奥莉：P1 选 Oleander，开启 Flag27。
- 三阶段奥莉：P1 选 Oleander，手动飞行、追踪弹、Boss Fred 和漩涡，不是剧情自动 AI。
  上述原有功能支持已调查的自由训练、本地 CPU、本地双人，不承诺其他模式。
- 天火普通 Fred（实验）：P1 天火、P2 必须普通奥莉，用于正常加载 Uni/Fred 资源。
  F9 召唤，Y 提前清理；约 600 次更新（10 秒）自动清理，冷却 60 次更新（约 1 秒）。
  当前场景已有 Fred 时拒绝重复召唤。普通 Fred 不使用三阶段 I/J/K/L 指令方案，
  不保证普通奥莉全部指令已移植。未独立实现资源预加载，不能任意选择 P2。
- Paprika Boss（训练实验）：仅普通自由训练，P1 选 Paprika，对手任意。
  站稳后 F6 切换 Flag27。剧情脚本用此标志开启 Boss 模式；用户确认实验可运行，
  但具体强化效果尚未明确，不宣称完整 Boss、增伤或全套招式已解锁。
  FG_Attack_Leap/Teleport 前景攻击尚未接入。
- Velvet Boss（训练实验）：仅普通自由训练，P1 选 Velvet，对手任意。
  站稳后 F6 请求 Boss_Install；到 Boss_Wind_Idle 后 F7/F8/F9 分别请求三档冰柱。
  需要等回龙卷风待机再出下一招。剧情的风推、定位与完整行为树未移植。
  用户已反馈独立实验可用；整合 UI 版本还需实际回归。
  Y 停止 Paprika/Velvet 实验并取消这两项勾选，不保证清除 Velvet 龙卷风！
  使用龙卷风后必须退出并重启游戏；不要直接继续对局或联机。
- 白鹤二气 Supernova：单独法球首次更新即退出，尚未成功，UI 禁用。
  不包含法球效果、二气演出、伤害或两格气消耗。

三阶段奥莉按键（与普通 Fred 不同）
O：切换飞行；WASD：低空移动；P：启动约 1.5 秒后追踪弹。
I：排队一次 Boss Fred 召唤；J/K：左右攻击；Shift 强化、Ctrl 组合，可叠加。
L：蓄力漩涡；至少半秒后再次 L 请求释放。等待收尾再出招。
Y：取消、清理 Fred、恢复普通控制。U：游戏暂停。
预留十个碰撞位，不替换地图。发红、锁招、对手短暂变小牛等历史异常
不宣称已经全部修复；恢复不完整时必须重启。

建议验证
Paprika：F6 开/关各试普通技、传送、受击和倒地恢复，并记录具体差异。
Velvet：F6 -> 等待龙卷风待机 -> F7/F8/F9 分别测试 -> Y -> 重启游戏。
天火：P1 天火 / P2 普通奥莉，F9 -> 等自动清理 -> 冷却后 F9，重复三次。
先单独勾选一个实验功能。整合版的单元/打包自检不替代实机回归。

安全与反馈
仅已调查的离线流程：原功能白名单 fightType=0 或 fightType=10 且 training=1；
新增 Velvet/Paprika 收窄到后者。不保证所有离线模式、场地、回合或重开流程。
工具注入 JavaScript、挂钩游戏原生函数并修改进程内存，不往游戏 Lua 插脚本。
不修改游戏硬盘资源和存档、不分发游戏素材；仍有闪退和状态残留风险。
关闭工具并重启游戏后再联机；白名单不是反作弊或联网安全保证。
不绕过版本校验；支持 EXE SHA256：
03E20EECE23F39FB1012061A5A7FF92F4B63DA23EB8EB641CF6EE379CBCE373D
未签名程序可能被安全软件提示，不要因此关闭安全软件。
日志在 EXE 旁 logs/ui-hook-<PID>.jsonl，仅本地保存，不自动上传。
反馈版本、模式、双方角色、按键顺序及日志；分享前自行检查日志内容。
