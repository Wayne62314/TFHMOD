TFHMOD UI 2.4.2-ui-bilingual1 — Windows x64 实验版

仅限离线、仅玩家 1。非官方工具，不是剧情最终 BOSS 的完整复刻。
弗雷德与漩涡恢复修复仍需游戏内验证，不能把模拟测试当作全部问题已解决。

下载与解压
https://github.com/Wayne62314/TFHMOD/releases/tag/v2.4.2-experimental
下载 TFHMOD-UI-2.4.2-bilingual1-windows-x64.zip，勿把自动生成的 Source code
当成运行版。完整解压到新的可写文件夹，例如 D:\TFHMOD-UI-242。
不需要放进游戏目录。保留 TFHMOD.exe 旁边的 _internal 文件夹。
已包含 Python、Frida、Tcl/Tk，不必安装 Python，不必运行 Setup.cmd。
不要混用不同版本文件；先关闭所有旧 TFHMOD 工具。

开始使用
1. 完全退出并重启游戏，尤其不要直接接管已经发红、卡住或提示清理失败的对局。
2. 从 Steam 正常启动游戏到主菜单，再运行 TFHMOD.exe。
3. 右上角 English 切换英文；中文按钮切回中文。状态和已有日志同步切换，
   不改变功能开关或重新连接。使用说明按钮打开当前语言的本文件。
4. 选择功能后点连接游戏。连接后必须返回选角重新进场；已在场内不会自动准备。

三个功能开关
- 大熊：P1 选 Arizona，进场加载 Huggles，选角预览仍可能显示 Arizona；不替换 P2。
- 普通强化奥莉：P1 选 Oleander，启用 flag27 强化。
- 三阶段奥莉：包含 flag27，以及手动飞行、追踪弹、Fred 和漩涡。
  不包含原剧情自动 AI、过场和完整演出。

按键（仅游戏窗口在前台时）
O                 进入飞行；再按 O 退出并请求清理。
W/A/S/D           有限范围低空移动。
P                 追踪弹，启动约 1.5 秒后使用。
I                 记住一次召唤请求，等待启动、冷却或动作结束；不会按住无限召唤。
                  等待约 5 秒游戏更新后到期；Y、退出飞行、换场或失焦会取消。
J / K             Fred 左右攻击，须先等出场和当前攻击结束。
Shift + J / K     强化攻击。
Ctrl + J / K      组合攻击。
Ctrl+Shift+J / K  强化组合攻击。
L                 Fred 出场后开始漩涡；蓄力至少半秒，再按 L 请求爆发。
Y                 取消、清理 Fred，恢复普通控制及原位置。
U                 留给游戏暂停；工具不读取 U。

漩涡结束后等待收尾再出招。不要在出场中连续召唤。部分底层诊断详情为英文。
本地键盘双人需避免游戏键位冲突；本工具未新增三阶段手柄映射。

首次回归测试
自由训练 P1 奥莉 → O → I → 等 Fred 出场 → J/K → L → 再按 L → 等收尾 →
P → Y → O → I 再次召唤，至少连续三轮。
通过后再测本地人机、双人、换回合和再战。
若提示恢复不完整，停止该对局并重启游戏，不要继续连按。

停用与反馈
先在游戏内按 Y，再断开或关闭工具，重启游戏以完全清除本次修改。
进入联网前必须关闭工具并完全重启游戏；离线白名单不是反作弊或联网安全保证。
日志在 EXE 旁 logs\ui-hook-进程号.jsonl，不会自动上传。
