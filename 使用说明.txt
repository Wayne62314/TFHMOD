TFHMOD 2.1.0 · 大熊离线分享版（Windows 64 位）

一、下载哪个文件
在 GitHub Release 的 Assets 中下载 TFHMOD-v2.1.0-windows-x64.zip。
不要把页面自动生成的 Source code (zip) 当成免安装运行版。

二、解压到哪里
右键 ZIP → 全部解压到独立、可写的文件夹，例如 D:\TFHMOD。
不需要放进游戏目录，不需要与游戏同盘，不要放进 data01。
保留 TFHMOD.exe、_internal 文件夹和其他配套文件，不要直接在压缩包里运行。
本分享版已自带 Python 和 Frida，无需安装 Python、无需运行 Setup.cmd。

三、使用步骤
1. 关闭所有旧版大熊工具。若刚使用过旧工具，先退出并重启游戏。
2. 从 Steam 正常启动游戏，等到主菜单，只开一个游戏实例。
3. 双击 TFHMOD.exe，看到 Ready (v2.1.0) 后保留工具窗口。
4. 进入普通自由训练、本地双人自由对战或本地人机对战。
5. 玩家 1 选择 Arizona，正常选择对手和场地。
6. 选角头像和预览仍是小牛，进入场地后玩家 1 加载大熊。玩家 2 不变。
7. 如果启动工具前已在场地内，返回选角重新选择，不会原地替换已创建角色。

四、停止
在工具窗口按 Ctrl+C 停止，再退出并重启游戏，完全清除这次内存改动。
工具不修改游戏安装资源，不会开机自启，不会在下次游戏启动时自动生效。

五、限制
仅支持当前已适配的 Windows Steam 构建，显示 V6.0.0.WIN 不代表二进制一定匹配。
支持的游戏 exe SHA256：
03E20EECE23F39FB1012061A5A7FF92F4B63DA23EB8EB641CF6EE379CBCE373D
游戏更新后校验失败会拒绝启用，不要强行绕过校验。
仅限离线模式。网络类型不放行，也未进行在线验证。
本版修复：训练对局类型 10、训练标志为 1 时不再被误拦截。
仍需不同电脑验证；全部招式、回合结算、再战、录像等未穷尽测试。
未进行数字签名；系统或安全软件可能提示风险。不要关闭安全软件或绕过组织策略。
不能保证兼容其他注入工具或 Mod；请勿多开同类工具。

六、出现问题
提示找不到游戏：确认游戏已在主菜单，且与工具使用同一用户、相同权限级别。
提示版本不匹配：停止使用，等待适配，不要修改哈希。
进场仍是小牛：确认 Ready、P1 选 Arizona、离线模式，并重新完成选角。
日志位于工具目录 logs；不会自动上传，反馈前请自行检查内容。
从不使用工具的游戏状态开始复现，记录模式、双方角色、发生阶段和相关错误。
